# Open-region coordinates

All 335 original regions labelled Bare soil / rock / sparse ground (class 4). Crops/grass and uncertain regions are not included. These labels do not establish that land is vacant, accessible, safe or available for use.

The table gives WGS84 / EPSG:4326 decimal degrees. Latitude and longitude have separate named columns. Centroids were computed in EPSG:32643 before transformation. Interior coordinates locate a point inside each patch; centroids can fall outside irregular polygons. Areas are square metres computed in EPSG:32643. Decimal precision is not surveyed accuracy.

The GeoJSON contains full polygon boundaries, including holes, using [longitude, latitude] coordinate order. Match segment_id across files. No boundaries or source classifications were changed.
